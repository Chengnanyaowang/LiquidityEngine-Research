# LiquidityEngine Research

**面向加密衍生品研究的、可审计 AI 工作流公开参考实现。**

这个仓库展示 LiquidityEngine 的公开技术理念：把市场状态、证据、AI 解释、本地权限核验和复盘记录组成一条可检查的研究链路。

它不是交易机器人、喊单服务、投资产品或资产管理工具。仓库中的行情、事件和决策均为合成示例；真实策略、规则阈值、模型提示词、实盘数据、账户信息和运行基础设施均保持私有。

公开版本重点说明四件事：

1. 一次研究判断使用了哪些市场事实；
2. AI 的解释与确定性权限核验如何分层；
3. 为什么某次判断会被等待或阻止；
4. 如何基于固定证据回放历史判断，而不是用新模型改写旧结论。
