# Security and repository boundary

## Supported scope

This repository contains only a public reference implementation. It must not contain live credentials, client data, exchange sessions, execution code, proprietary prompts, strategy thresholds, or real decision records.

## Reporting a concern

Please do not open a public issue for a suspected secret, privacy concern, or security vulnerability. Email **pacinocorleone143@gmail.com** with a concise description and the affected path or commit SHA.

We will acknowledge reports as soon as practical and rotate or remove exposed credentials immediately when applicable.

## Important limitation

Removing a file from a Git branch does not remove it from repository history. Any accidental credential exposure requires revocation or rotation; deletion alone is not a remedy.
